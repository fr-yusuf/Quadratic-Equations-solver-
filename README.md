# Quadratic Equation Solver 

Hi! 👋 I'm Mohammad Yusuf, and I made this as a 11th grader, and this is my **first coding project**.

It solves quadratic equations (ax² + bx + c = 0) and shows the working.

🔗 **Try it live:** https://fr-yusuf.github.io/Quadratic-Equations-solver-/

## What it can do
- Finds the roots, including complex ones
- Shows a step-by-step solution
- Shows the vertex, axis of symmetry and more
- Draws the graph of the parabola

## How to use
1. Type the values of **a**, **b** and **c**
2. Tap **Solve**
3. Tap **Reset** to start again
